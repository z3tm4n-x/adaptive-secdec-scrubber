# Paired delta analysis для финальных серий

## Назначение

Для каждого seed сравниваются adaptive-стратегии с fixed-стратегией на одном и том же потоке инжектированных событий. Дельта считается как `adaptive - fixed`.

Отрицательная дельта по `busy_percent` означает снижение занятости памяти. Положительная дельта по `unique_uncorrectable_words` означает увеличение числа уникальных слов, перешедших в неустранимое состояние.

## Интерпретация для статьи

Основной вывод следует делать по `busy_percent` и `unique_uncorrectable_words`. `uncorrectable_detections` является вспомогательной телеметрической метрикой, поскольку зависит от частоты повторного обхода уже повреждённых слов.

Если доверительный интервал по `unique_uncorrectable_words` включает ноль или близкие к нулю значения, корректная формулировка — «сопоставимое число уникальных неустранимых слов». Если интервал строго положителен, следует писать «снижение занятости достигается ценой умеренного увеличения числа уникальных неустранимых слов».
