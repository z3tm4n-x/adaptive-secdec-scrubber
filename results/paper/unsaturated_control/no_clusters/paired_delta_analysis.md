# Paired delta analysis для контрольной серии вне насыщения

## Назначение

Для каждого seed adaptive-стратегии сравниваются с fixed-стратегией на одном и том же потоке инжектированных событий. Дельта считается как `adaptive - fixed`.

Отрицательная дельта по `busy_percent` означает снижение занятости памяти.
Положительная дельта по `unique_uncorrectable_words` означает увеличение числа уникальных неустранимых слов.

## Интерпретация

Если доверительный интервал по `unique_uncorrectable_words` строго выше нуля, снижение занятости в данной контрольной серии достигается ценой увеличения числа уникальных неустранимых слов. Если интервал включает ноль, корректная формулировка — сопоставимое число уникальных неустранимых слов.
