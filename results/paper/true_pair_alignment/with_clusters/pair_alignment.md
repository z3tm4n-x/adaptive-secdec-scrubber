# True pair alignment по `pair_id`

## Назначение

Проверяется согласование накопительных пар с управляющим уровнем по истинным метаданным генератора. Пары группируются по `pair_id`, а не восстанавливаются эвристически по адресу и временному разрыву.

## Общая сводка

- Число seed: 10
- Всего метаданных событий: 4900
- Корректно разобранных накопительных пар: 400
- Некорректных pair_id-групп: 0
- Пар с разными адресами first/second: 0
- Сдвинутых событий внутри накопительных пар: 0
- Сдвинутых событий всех типов: 8
- Порог агрессивного уровня: level >= 6

## Интерпретация

Этот отчёт закрывает методическое замечание о восстановлении накопительных пар по эвристике. Накопительные пары анализируются по истинным полям `pair_id` и `pair_role`, записанным генератором событий.

Распределение уровней показывает, на каких участках управляющего ряда расположены пары. Это не является метрикой надёжности само по себе, но проверяет, что сценарий пар действительно согласован с управляющей политикой и может использоваться для анализа накопительного механизма.
