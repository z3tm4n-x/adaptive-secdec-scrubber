# Спецификация проекта

## 1. Назначение

Цель проекта — разработать и исследовать аппаратную архитектуру контроллера адаптивного скраббинга памяти с кодом SECDED.

Контроллер должен изменять интервал запуска скраббинга по внешнему дискретному уровню сбойной обстановки.

## 2. Основные ограничения

1. Код коррекции не изменяется во время работы.
2. Используется код SECDED.
3. Изменяется только интервал запуска скраббинга.
4. Оценка сбойной обстановки поступает извне.
5. Контроллер не рассчитывает радиационную модель.
6. Память моделируется как массив кодовых слов.
7. Один цикл скраббинга — полный последовательный проход по защищаемой области памяти.

## 3. Параметры кодового слова

Информационные биты: 32.

Проверочные биты: 7.

Длина кодового слова: 39 бит.

Структура:
- 6 проверочных битов Хэмминга;
- 1 общий бит чётности;
- 32 информационных бита.

## 4. Режимы управления интервалом

1. Постоянный интервал.
2. Табличное преобразование уровня сбойной обстановки в интервал скраббинга.
3. Пороговая стратегия с гистерезисом.

## 5. Внешние управляющие сигналы

Предварительный состав:
- ctrl_level — дискретный уровень сбойной обстановки;
- ctrl_valid — признак допустимости уровня;
- ctrl_update — признак обновления уровня.

## 6. Безопасный режим

Если внешний управляющий сигнал не обновлялся дольше допустимого времени, контроллер должен перейти на заранее заданный консервативный интервал скраббинга.

## 7. Основные счётчики

- число циклов скраббинга;
- число прочитанных слов памяти;
- число записей исправленных слов;
- число исправленных ошибок;
- число неустранимых ошибок;
- число переключений интервала;
- число переходов в безопасный режим.

## 8. Метрики сравнения стратегий

- число циклов скраббинга;
- число исправленных ошибок;
- число неустранимых ошибок;
- доля занятости интерфейса памяти;
- аппаратные затраты контроллера.
