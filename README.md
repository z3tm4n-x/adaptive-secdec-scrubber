# Adaptive SECDED Memory Scrubbing Controller

## Назначение проекта

Репозиторий содержит синтезируемую RTL-модель контроллера адаптивного скраббинга памяти с кодом SECDED 32+7, программный генератор потоков ошибок на основе ряда радиационной обстановки и воспроизводимый pipeline численного сравнения стратегий скраббинга.

Проект предназначен для пятой статьи диссертационной серии: архитектурно-имитационная верификация стратегий адаптивного скраббинга, согласованная с ранее полученными теоретическими моделями.

## Основная идея

Контроллер выполняет последовательный скраббинг защищаемой области памяти и изменяет период полного прохода в зависимости от внешнего дискретного уровня сбойной обстановки.

Поддерживаются три стратегии:

1. `fixed` — постоянный период скраббинга.
2. `table` — табличное отображение уровня обстановки в период скраббинга.
3. `threshold` — пороговая стратегия с гистерезисом.

В финальной постановке статьи используется `risk_policy`: расчётная политика, построенная по полному ряду `ν(t)` и затем перенесённая в архитектурно достижимую RTL-шкалу интервалов.

## Важная семантика интервала

В актуальной версии RTL `selected_interval` означает целевой период полного прохода скраббинга, а не дополнительную задержку после завершения прохода.

Поскольку последовательный проход памяти занимает ненулевое число тактов, контроллер использует:

effective_wait_interval = max(1, selected_interval - last_pass_duration)
